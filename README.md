- **Organization:** GVI Tech JSC

- Binary Options
- DEX / Ecosystem (on-chain wallets)
- Staking · P2P · Affiliate (MLM)
- KYC / AML · Compliance (NQ-05, NĐ-284)
- Admin Dashboard · CMS · Blog
